# 二子玉川花火 観覧マップ

世田谷区たまがわ花火大会と川崎市制記念多摩川花火大会（2026年10月3日（土）18:00–19:00、同時開催）をまとめて扱い、穴場の観覧場所を提案する Web アプリ。

- **地図**：国土地理院の淡色地図の上に PLATEAU の建物を 3D で表示する。10m 以上の建物は「屋上から花火が見える割合」で色分けしている（灰→黄→オレンジ）。
- **スポット一覧**：公式会場、河川敷、高台の公園、ホテルや商業施設など20か所を、見える割合の高い順に並べる。当日立入禁止の場所（兵庫島公園、橋の上など）は、初期設定では非表示。
- **3D ビュー**：スポットや地図上の建物をクリックすると、その場所・その階から見える景色を three.js で表示し、花火を打ち上げる。「世田谷の方を見る／川崎の方を見る」で向きを切り替えられる。
- **共有リンク**：`#spot=excel` でスポットを選び、`#spot=excel&view=1` で 3D ビューを開く。

## 使い方

```bash
npm install
npm run dev          # http://localhost:5173
```

`public/data/` は作成済みのデータとしてコミットしてある。作り直す場合は、次のコマンドを実行する（uv と Node 22.18 以上が必要）。

```bash
npm run data         # PLATEAU と標高タイルを取得（約30MB）→ 見える割合を計算
npm run data:build   # scripts/spots.json を編集したあとは、これだけでよい
```

スポットは `scripts/spots.json` で管理する。`floors: [10, 20]` を指定すると階ごとに、`roof: true` を指定すると屋上から、`levels` を指定すると任意の高さから計算する。

## 見える割合の計算方法

1. 各打上地点の上空に、3号〜6号玉の開花高度（120／160／190／220m）×5か所、合わせて20点ずつの「開花点」を置く。2026年は世田谷の最大玉が6号に縮小された。川崎は最大玉を公表していない。
2. 観覧地点の目の高さ（地面または床面＋1.6m）から各開花点へ視線を引く。その途中を、建物（PLATEAU の実測高さで立ち上げた立体）や地形（国土地理院の 5m 標高データ）がさえぎるかを 6m 刻みで調べる。
3. さえぎられなかった開花点の割合を、世田谷側・川崎側それぞれで出す。観覧地点が建物の中にある場合、その建物自体は視線の判定から除く。

`node scripts/debug-spot.ts <緯度> <経度> [地面からの高さ]` を実行すると、ある地点から見えない理由（何m先のどの建物か、地形か）を確認できる。

## 限界と注意

- **打上地点は推定**。公式の会場マップから、±250m 程度の精度で推定している。
- **木、看板、仮設物、人混みは計算に入っていない。** 公園や崖線の上では、木で実際より見えにくいことが多い。
- 河川敷のスポットのうち3か所は、公表されている座標が堤防の外側（住宅地）を指していたため、標高データを使って河川敷の位置に補正した。
- 私有地や建物の屋上は、通常は立ち入れない。地図上の建物の色は「その高さから見えるか」を示すだけで、入れるかどうかは示していない。
- 情報は 2026-09-28 時点のもの。当日の規制は公式サイトで確認すること。
  - 世田谷区たまがわ花火大会：https://tamagawa-hanabi.com/
  - 川崎市制記念多摩川花火大会：https://www.k-kankou.jp/fireworks/
